# Architecture decision records

Each file here records one decision: the context, what was decided, and
what follows from it. Records are numbered and never rewritten. To change a
decision, add a new record that supersedes the old one and update
`docs/PLAN.md`.

Copy [`template.md`](template.md) to start a new record.
